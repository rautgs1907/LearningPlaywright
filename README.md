# Learning Playwright - Chapter 02

This repository contains scripts and exercises for learning Playwright automation, focusing on JavaScript basics and environment setup.

## Project Structure

- `01_basics.js`: Introduction to JavaScript fundamentals.
- `02_basics.js`: Further exploring JavaScript core concepts.
- `03_verify_setup.js`: Script to verify the Node.js environment and platform.
- `04_hot_code.js`: Performance demonstration of JavaScript execution (hot functions).

## Getting Started

1. Ensure you have [Node.js](https://nodejs.org/) installed.
2. Clone the repository:
   ```bash
   git clone https://github.com/rautgs1907/LearningPlaywright.git
   ```
3. Navigate to the directory:
   ```bash
   cd AI_Automation/chapter/chapter_02
   ```
4. Run any script using Node:
   ```bash
   node 03_verify_setup.js
   ```

## Requirements
- Node.js (v14 or higher recommended)
